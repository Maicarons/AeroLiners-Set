AeroLiners Set (寰宇飞机) — Changelog
======================================

This file is bundled into every release archive and is also used as the
GitHub Release notes. Counts reflect the fleet at the time of each release.

本文件随每个发布包一同打包，并用作 GitHub Release 说明。各项数字为对应版本
发布时的机队规模。


## v1.1.2 (2026-10-01)

- Fixed aircraft speed handling: the per-flight-state speed callback is now a
  constant cruise speed. OpenTTD caches the speed-property callback result and
  only refreshes it at vehicle creation, airport state changes and savegame
  load, so state-dependent values got stuck (planes stayed at runway speed
  after liftoff; after save/reload the runway speed wrongly equalled the
  cruise speed).
- 修复飞机速度机制：速度回调改为恒定返回巡航速度。OpenTTD 会缓存速度属性回
  调结果，仅在载具创建、机场状态切换和读档时刷新；此前按飞行状态改写速度会
  导致缓存卡在旧值（起飞离地后仍为跑道速度；读档后跑道速度错误地等于巡航
  速度）。现在地面滑行 / 进近 / 刹车减速由游戏原生状态机按巡航速度自动派生，
  存档前后行为一致。
- Added tools/fix_speed_constant.py (batch fix / realign) and rewrote
  tools/check_speed_mismatch.py to guard the new convention; updated
  gen_placeholder_aircraft.py and add_aircraft.py accordingly.
- 新增 tools/fix_speed_constant.py（批量修复/对齐），重写
  tools/check_speed_mismatch.py 守护新约定，并同步更新占位机生成器与克隆
  脚本。


## v1.1.1 (2026-08-11)

- Wrote back verified real-world performance data (range / seating capacity /
  cruise speed) for all 216 aircraft.
- 为全部 216 款机型核实并写回真实世界性能数据（航程 / 座级 / 巡航速度）。
- The 71 placeholder aircraft still borrow their donor sprites; only their
  stats were corrected — graphics are unchanged.
- 71 款占位机型仍借用 donor 精灵图，本次仅修正参数，图形未作替换。
- 42 aircraft keep estimated purchase-cost factors and 3 retain estimated
  range/cruise, because no public list price or reliable source is available.
- 42 款机型保留估算的购买成本系数，另有 3 款保留估算的航程/巡航——因无公开
  目录价或可靠来源。


## v1.1 (2026-08-09)

- Added 17 gap-filler airliners and the Cessna family, widening coverage.
- 新增 17 款补齐机型缺口的客机以及塞斯纳（Cessna）家族。
- Fleet grew to 216 models / 2264 liveries across 30 manufacturers. New
  manufacturers include COMAC, Cessna, AVIC, Irkut, Sukhoi, Yakovlev,

  Convair, Hawker Siddeley and Britten-Norman.
- 机队扩展至 216 款机型 / 2264 种涂装 / 30 家制造商。新增厂商含中国商飞、
  塞斯纳、中航工业、伊尔库特、苏霍伊、雅克夫列夫、通用原子、皮拉图斯、PZL、
  雷神、LET、德哈维兰、维克斯、康维尔、霍克·西德利、布里顿-诺曼。
- Fixed placeholder aircraft parameters (introduction year, capacity, range).
- 修正占位机型的参数（引入年份、载客量、航程）。
