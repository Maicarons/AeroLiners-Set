AeroLiners Set (寰宇飞机) — Changelog
======================================

This file is bundled into every release archive and is also used as the
GitHub Release notes. Counts reflect the fleet at the time of each release.

本文件随每个发布包一同打包，并用作 GitHub Release 说明。各项数字为对应版本
发布时的机队规模。


## v1.1.4 (2026-11-20)

- Added static Action 0 `cost_factor`, `speed` and `running_cost_factor`
  fallbacks to all 216 aircraft. The graphics callbacks remain the in-game
  source of truth, but AIs such as AAAHogEX read the static properties and
  previously saw 0, causing a divide-by-zero crash (issue #4).
- Added `tools/static_props.py` to keep the static values in sync and a CI
  check that fails when any aircraft is missing them.
- Updated the BaNaNaS/installation/docs pages: the in-game entry is
  `AeroLiners-Set` (GRFID `AERO`), separate from the upstream WAS entry.
- 为全部 216 款机型补充静态 Action 0 `cost_factor`、`speed` 与
  `running_cost_factor` 兜底值。游戏内仍由 graphics 回调覆盖，但
  AAAHogEX 等 AI 读取静态属性时不再看到 0，修复除零崩溃（issue #4）。
- 新增 `tools/static_props.py` 保持静态值与 graphics 回调同步，并加入 CI
  检查，缺失时直接失败。
- 同步 BaNaNaS/安装/下载文档：游戏内条目为 `AeroLiners-Set`（GRFID `AERO`），
  与上游 WAS 条目区分。


## v1.1.3 (2026-11-14)

- Decoupled release packaging: `bundle.json` is now the single source of truth
  for version, GRF ID, bundled docs and archive names; `CMakeLists.txt` and the
  release workflow both call `scripts/bundle.py` instead of duplicating metadata.
- `scripts/bundle.py` substitutes the readme placeholders (revision + GRF MD5),
  writes LF-only docs, builds the BaNaNaS `<grfid>-<name>-<version>.tar` plus
  `.tar.gz`, and self-verifies layout, GRF ID and MD5.
- Removed legacy build helpers (`scripts/ProcessDocs.cmake`, one-off verification
  scripts) and unused historical asset directories (`documentation/`, `sprites/`,
  `greyscales/`); refreshed the docs that referenced them.
- 解耦发布打包：`bundle.json` 成为版本、GRFID、随包文档清单与包名的唯一配置源；
  `CMakeLists.txt` 与发版 workflow 统一调用 `scripts/bundle.py`，不再各自硬编码。
- `scripts/bundle.py` 负责替换 readme 占位符（修订号 + GRF MD5）、把文档转为 LF、
  生成 BaNaNaS 格式的 `<grfid>-<name>-<version>.tar` 与 `.tar.gz`，并自校验布局、
  GRFID 与 MD5。
- 删除旧构建辅助脚本（`scripts/ProcessDocs.cmake`、一次性核对脚本）与不再使用的
  历史素材目录（`documentation/`、`sprites/`、`greyscales/`），并同步修正相关文档。


## v1.1.2 (2026-10-01)

- Fixed aircraft speed handling: the per-flight-state speed callback is now a
  constant cruise speed. OpenTTD caches the speed-property callback result and
  only refreshes it at vehicle creation, airport state changes and savegame
  load, so state-dependent values got stuck (planes stayed at runway speed
  after liftoff; after save/reload the runway speed wrongly equalled the
  cruise speed).
- 修复飞机速度机制：速度回调改为恒定返回巡航速度。OpenTTD 会缓存速度属性回
  调结果，仅在载具创建、机场状态切换和读档时刷新；此前按飞行状态改写速度会
  导致缓存卡在旧值（起飞离地后仍为跑道速度；读档后跑道速度错误地等于巡航
  速度）。现在地面滑行 / 进近 / 刹车减速由游戏原生状态机按巡航速度自动派生，
  存档前后行为一致。
- Added tools/fix_speed_constant.py (batch fix / realign) and rewrote
  tools/check_speed_mismatch.py to guard the new convention; updated
  gen_placeholder_aircraft.py and add_aircraft.py accordingly.
- 新增 tools/fix_speed_constant.py（批量修复/对齐），重写
  tools/check_speed_mismatch.py 守护新约定，并同步更新占位机生成器与克隆
  脚本。

- 为全部 216 款机型核实并写回真实世界性能数据（航程 / 座级 / 巡航速度）。
