## What is AeroLiners Set?

**AeroLiners Set (寰宇飞机)** is a **NewGRF** (New Graphics Resource File) for [OpenTTD](https://www.openttd.org/). Its goal is to bring real-world airliners and freighters — both recent and historic — into OpenTTD, and to let every aircraft be refit into the **authentic livery** of a real airline.

- Most of the original aircraft sprites were drawn by **PikkaBird** and originally shipped with the **AV8** set. AeroLiners Set adds authentic liveries on top, and the team has drawn some models themselves.
- AeroLiners Set can contain up to **65535** aircraft (thanks to OpenTTD's NewGRF engine pool), instead of the old limit of 48.
- It can be loaded alongside other aircraft NewGRFs without conflict.

> This project (`Maicarons/AeroLiners-Set`) is an independent continuation of the upstream `RvP93/WorldAirlinersSet` (World Airliner Set, WAS). Documentation is maintained in both Simplified Chinese and English with VitePress.
