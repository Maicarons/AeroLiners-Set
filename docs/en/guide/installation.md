# Installation & Usage

## Supported versions

AeroLiners Set currently supports **OpenTTD > 0.7.0 only**, because that version introduced support for more vehicle models, allowing the NewGRF to contain up to 65535 aircraft. AeroLiners Set **does not support TTDPatch** (same reason).

AeroLiners Set can be loaded alongside other aircraft NewGRFs without conflict.

## Getting AeroLiners Set

- **Stable release**: via the in-game **BaNaNaS** content downloader (stable versions only).
- **Latest build**: download the nightly `.tar` package from the development homepage.
- **Build from source**: see [Building from Source](/guide/building).

## Installation methods

### Method 1: Manual installation

1. Download the `.tar` package from the development homepage.
2. Place it into OpenTTD's `data` directory:
   - **Windows**: usually the `Documents/OpenTTD` folder.
3. If there is no `.tar` file, unzip the downloaded `.zip` into the `data` directory.

### Method 2: Via BaNaNaS

1. Open OpenTTD's **Content** list.
2. Find the **AeroLiners Set** entry and click **Download**.

## Enabling in-game

1. Open the **NewGRF Settings** window.
2. Click **Add**.
3. Select **AeroLiners Set** from the list.
4. Apply the settings and start or reload the game.

## Using AeroLiners Set

It is very simple:

1. Build the aircraft you want.
2. Click the **Refit** button; you will see a list of cargo entries, each followed by its livery name.
3. The first livery is usually **Greyscale**.
4. Select a livery and click **Refit Vehicle** to apply it.

::: tip
Greyscale is the default greyscale base livery with no airline markings — ideal as a blank or base appearance.
:::
