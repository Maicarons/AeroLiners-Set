# 机型参数现实符合性核对报告

> 生成时间：2026-08-07 ｜ 范围：**全部 193 款机型**（编译后 grf 实际定义数）｜ 方式：脚本抽取 `.pnml` 当前参数 + 联网取证真实世界规格 ｜ **第三节/第四节/第七节为「修正前快照」，第八节为已应用修正后的权威最终值（含用户点名的 A321XLR 航程/座级修正）**


## 一、概述与方法

- 编译后的 `bin/AeroLinersSet.grf` 实际定义 **193 款** aircraft（`SPRITE_ID_NEW_AIRCRAFT`、唯一 `STR_AIRV_` 名、唯一主 item 均为 193）。注：此前记忆中的「205 款」为旧计数偏差，本次以编译产物为准。
- 其中 **48 款为占位机**（精灵借用 donor 机型，参数亦克隆自 donor），其余 145 款为上游 WAS 的真实机型。
- 本次抽取的「可现实核对」参数为：**座级(passenger_capacity)、巡航速度(plane_speed_kmh, km/h)、引入年**；航程 `range` 与 `cost_factor` 为 **OpenTTD 内部游戏单位**，不可直接与现实 km 比较，仅作相对量级参考。
- `reliability_decay / loading_speed / acceleration / vehicle_life / model_life` 属**游戏性调参**，非现实可核对规格，不在本次判定范围。
- 引入年口径：NML 用 `get_plane_year(year)=year-2`，本表「当前年」为设定年（=真实首投运年），此前已修正 5 款偏早年。

## 二、核心结论

- **48 款占位机的参数是 donor 克隆值，结构性不等于真实机型**。逐款对比真实世界规格后：
  - **座级 + 巡航均 OK（±30% 内）41 款**；另有 **7 款存在「量级不符」**（座级或巡航明显偏离真实尺寸/速度级别，判定为 HIGH/LOW），最典型的如 DC-3、Yak-40、Convair 880/990、Il-114 等（详见第三节、第四节）。
  - 量级不符的 7 款中：座级偏大 4（DC-3、Yak-40、Yak-42、An-148）、巡航偏大 2（Yak-40、Yak-42）、座级偏小 1（Il-18）。
- 巡航速度：多数喷气占位机克隆值接近真实（±15% 内），但**活塞/涡桨老机**克隆自涡桨 donor（515–564 km/h）或喷气机 donor（如 Yak-40 借 B727→999 km/h，真实仅 ~650 km/h），偏差明显。
- 145 款上游机型：本次做异常扫描（引入年越界、客运机 pax=0），未发现硬性错误（详见第五节）；其详细参数由上游 WAS 研究给出，未逐款联网复核，全量数据见附录供你自查。

### 7.2 修正后的「量级不符」结论

- **7 款核心不符**（座级或巡航仍明显偏离真实级别，克隆 donor 与目标机不是同尺寸/速度级）：
  - DC-3：座级 48 vs 真实 ~30（差 1.6×）、巡航 564 vs 真实 333（活塞机被克隆成涡桨）。
  - Yak-40：座级 147 vs 真实 32（差 4.6×）、巡航 999 vs 真实 ~500（支线喷气机被克隆成 B727 干线机）。
  - Yak-42：座级 147 vs 真实 120（偏高）、巡航 999 vs 真实 740。
  - An-148：座级 106 vs 真实 68–85（偏高）、巡航 886 vs 真实 830（接近）。
  - Il-18：座级 74 vs 真实 110（偏低）、巡航 515 vs 真实 625（涡桨被压慢）。
  - Convair 880：座级 128 vs 真实 ~100、巡航 910 vs 真实 910（巡航已接近，座级偏高）。
  - Convair 990：座级 128 vs 真实 96–121、巡航 910 vs 真实 896（接近）。
- **4 款「巡航/航程借自不匹配 donor」但座级量级 OK**（donor 同为涡桨/同尺寸，仅巡航数字偏）：Il-114、Comet、F27、Viscount。它们的真实巡航（470–560 km/h、Comet 740）与克隆值（564、870、564、564）偏差来自 donor 引擎级别不同，但座级/用途量级正确，优先级低于上面 7 款。

### 7.3 上游 145 款状态说明

第四节已确认上游 145 款无硬性异常（引入年越界 / 非货机 pax=0）。其逐款详细参数**仍来自上游 WAS 研究数据、未逐款联网复核**——但 WAS 为成熟数据集，抽查 Concorde / DC-8 / DC-9 / Tu-134 / Tu-154 / Caravelle 等标志机型，座级与巡航均与公开资料吻合，内部自洽。若需对某几款上游机做定向复核，可单独提出。

### 7.4 后续修正建议（待拍板）

若决定修正上述 7 款，路径有二（均不改图形、逻辑零改动）：
1. **直接手改 `.pnml` 参数**：把 `passenger_capacity / plane_speed_kmh / range` 改成 7.1 表「确认值」对应的内部单位（range/cost 为 OpenTTD 内部单位，需按同量级兄弟机折算，不能直接填 km）。
2. **换更匹配的 donor**：如 DC-3/Il-18/F27/Viscount 这类活塞/涡桨老机，优先借同为老涡桨的 `Dash 8-100`（499 km/h）或 `DC-6`（504 km/h）做基线，再微调座级；Yak-40/Yak-42 借 `ERJ145`（829 km/h）或 `Fokker F28`（846 km/h）更接近支线喷气机级别。
