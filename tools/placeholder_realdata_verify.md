# 占位机型真实数据联网核对报告

> 生成时间：2026-08-10
> 范围：AeroLiners Set 全部 **71** 款占位机型（源码 `src/gfx/...` 中借 donor 精灵、无独立手绘像素图的机型）
> 目标：联网核对每款占位机的真实世界规格（座级 / 最大航程 / 巡航速度 / 服役年），比对源码现参数，修正偏差。

## 1. 方法

1. **基线抽取**：用 `tools/_extract_ph_params.py` 解析 71 款占位机 `.pnml` 中已烘焙的参数（座级、邮件舱、巡航 `plane_speed_kmh`、引入年、内部 `range` 值）。
2. **航程换算**：项目既定经验系数 `真实航程 km ≈ 内部 range 值 × 5.5`，故 `内部值 ≈ 真实 km ÷ 5.5`。
3. **联网核对**：对每款机型用 WebSearch 检索权威来源（空客/波音/商飞官网、维基/百度百科、民航媒体）确认真实座级、最大航程 km、巡航速度、首次商业运营年。
4. **分组**：
   - **12 款旧版**（由 `tools/add_aircraft.py` 生成，无 OVERRIDES，直接克隆 donor 参数，从未显式核对）：A220-300、A319neo、A321neo、A330-900neo、A350-1000、737 MAX 10、737 MAX 9、777X、787-10、C909、C919、E195-E2。
   - **59 款新版**（由 `tools/gen_placeholder_aircraft.py` 生成，带 `OVERRIDES`，已在 2026-08-07/09 的历史任务 #28–#37 中联网核对并写入真实值）。

## 3. 59 款新版核对结论

- 这 59 款的真实值已在历史任务 #28–#37 中通过 WebSearch 写入 `OVERRIDES` 并实测编译，基线抽取显示其航程/座级普遍准确。
- 本次额外**抽样复核 6 款代表性机型**，全部吻合：
  - **A321XLR**：当前 8701 km ↔ 真实 8700 km ✓；座级 210（真实 180–220）✓
  - **C929**：当前 12001 km ↔ 真实 12000 km ✓；座级 280（真实 280）✓
  - **777-8**：当前 16698 km（真实 16110–17595 区间，随波音 2026 改标变动）✓；座级 365（真实 350–425）✓
  - **A330-800neo**：当前 14998 km ↔ 真实 15000 km ✓；座级 264（真实 257–271）✓
  - **MC-21**：当前 6000 km ↔ 真实 6000–6400 km ✓；座级 180（真实 163–211）✓
  - **A220-100**：当前 6298 km ↔ 真实 6390 km ✓（差 1.4%，可接受）
- **结论：59 款无需改动。**

## 4. 已知未修正项（说明，非遗漏）

- **巡航速度**：空客窄体（A220/A319neo/A321neo/A320neo 系）统一为 833、波音 737 系统一为 975，均为 donor 克隆值。真实巡航约 840–900 km/h，游戏值有 ±10% 偏差；但这与整机队既有设定一致（属上游 WAS 的历史 stylization），单独改这 4 款反而会破坏机队内速度梯度，**本次不动**。
- **A350-1000 航程**：16225 vs 真实 16700 km（差 3%），落在合理区间，未改。

## 6. 重新编译

- 本次改动**仅**为 `range:` 后的整数常量，nml 语法零风险。
- 本沙箱环境无 C 编译器（gcc/clang/MSVC 均不在 PATH），无法跑 `cmake` 全流程（该流程先用 C 预处理器展开 `#include`/`#define`，再用 `nmlc` 编译）。
- **需在用户构建机 / GitHub Actions 上用正常流程重新编译 `bin/AeroLinersSet.grf`**，改动才会烘焙生效。
- 自动发版 workflow（`.github/workflows/release.yml`）监听 `v*` tag 推送，发版时即自动重编。
